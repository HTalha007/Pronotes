Hızlı yardımcı fonksiyon

Gecikmeli metin aramaları için kullanılan debounced işlev yapısı:

// Belirtilen süre boyunca çağrıları bekletir
function debounce(fn, ms = 300) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}
